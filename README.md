# PERSONAL FINANCE MANAGER

C'est une aplication web qui permet à l'utilisateur de gérer un budget 
personnel mensuel, de planifier ses charges récurrentes à venir et de suivre ses objectifs 
d'épargne. 
L'objectif est de fournir un outil simple et visuel pour aider l'utilisateur à mieux comprendre ses 
finances, sans connecter de vraies données bancaires. Toutes les données sont stockées 
localement dans le navigateur (localStorage). 

# Objectif 
• Suivre revenus et dépenses sur un mois donné, par catégorie et sous-catégorie. 
• Visualiser les charges récurrentes à venir (loyer, abonnements, dette) sur les semaines 
suivantes. 
• Définir des objectifs d'épargne avec montant cible et y verser de l'argent progressivement. 
• Filtrer et analyser l'historique de toutes ses transactions. 
• Personnaliser ses propres catégories et sous-catégories. 
• Persister les données côté client, sans backend.
